# Reading this site as an agent

This is Victor's portfolio site. It is read-only: no sign-in, no keys.

- **Pages:** the full list is in [/sitemap.xml](https://vb-pm.vdb1.workers.dev/sitemap.xml).
- **Markdown:** send `Accept: text/markdown` with any page request and you get the page as markdown instead of HTML.
- **Status:** [/health](https://vb-pm.vdb1.workers.dev/health) answers `{"status":"pass"}` when the site is up.
- **Machine description:** [/openapi.json](https://vb-pm.vdb1.workers.dev/openapi.json) (OpenAPI 3.1).
- **Catalog:** [/.well-known/api-catalog](https://vb-pm.vdb1.workers.dev/.well-known/api-catalog) (RFC 9727).
